# Hospital Reservation System

A desktop hospital reservation system developed in **C#** as part of a C# programming course PV178.

## Features

* User and departments management
* Doctor management and department assignment
* Working hours and days off management
* Viewing departments, doctors, and their availability
* Patient reservations in a calendar view

## Technologies

* **C#**
* **WPF**
* **MVVM Architecture**
* **Object-Oriented Programming (OOP)**
* **MS SQL Server (LocalDB)**
* **Entity Framework**

## Getting Started

1. Clone or download the repository.
2. Open the `.sln` file in **Visual Studio**.
3. Make sure to have SQL Server LocalDB installed.
4. Build and run the project.
